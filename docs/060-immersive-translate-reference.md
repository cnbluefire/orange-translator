# 沉浸式翻译 CRX 策略分析

分析对象：`resources/沉浸式翻译.crx`，版本 `1.34.2`。解包产物仅放在 `temp/immersive-reference/`，不进入发布代码。

## 默认调度策略

- `translationStartMode: "dynamic"`：默认动态翻译，而非立即处理整页。
- `immediateTranslationTextCount: 4999`：即时阶段设有文本预算。
- `immediateTranslationScrollLimitScreens: 1`：即时阶段限制滚动预取距离。
- `generalRule.visibleObserverScreens: [0, 0, 2, 0]`：用可见范围观察器调度候选正文，并允许站点规则覆盖。
- `enableDeferredRender: true`、`deferredRenderRootMargin: "0% 0px 35% 0px"`：请求完成与译文渲染分开，靠近可见区时再渲染。
- “翻译网页”和“立即翻译到页面底部”是两个独立命令，默认行为不会全页翻译。

当前项目采用更保守的固定策略：当前视口加下方一屏；滚动中不插入，停止约 280ms 后处理新范围；不会自动翻译到底部。

## 正文与 DOM 管理

- 使用 TreeWalker 和站点规则识别段落，不只依赖 `p` 标签。
- 通过 `data-imt-p` 和内部标记避免重复解析。
- 对动态页面使用 MutationObserver，并识别自身插件更新，避免观察器循环。
- 支持 body 替换、SPA URL 变化、延迟加载和新增正文。
- 清理时恢复原始 DOM，并移除段落标记和观察器。
- 对 `pre`、表单、iframe、媒体、隐藏元素及站点排除选择器有独立规则。

当前项目取用其中的轻量部分：段落标记、动态新增正文监听、过滤自身译文 DOM、停止和还原时清理观察器。

后续已增加本地规则兼容层和受控 iframe 支持：

- `src/site-rules.js` 只保存正文翻译所需字段，不包含字幕、图片、会员和规则同步功能。
- 当前本地规则覆盖 GitHub、Reddit、Medium 和 Substack，并保留通用规则回退。
- 站点规则中的容器选择器不会与内部段落同时翻译；候选节点会做嵌套去重，优先保留最深正文块。
- 内容脚本注入所有 frame，包括 `about:blank` 与继承来源的 frame。
- 顶层页面统一显示控制条，后台向标签页所有 frame 广播明确的开始、暂停、继续和还原命令。
- 子 frame 独立按自身可视区处理正文；没有正文候选的 frame 不产生请求。
- 暂未接管 closed Shadow DOM；这需要在页面脚本之前 Hook `attachShadow`，侵入性和兼容风险较高。

## 批处理与接口成本

- 普通 AI 服务常见默认每批 4 段。
- 推荐 AI 批协议默认 16 项，上限 32 项，并带稳定条目标记与校验。
- Google、DeepL 等原生列表接口可配置更大的批量数量。
- 单段过长时先切片，返回后按顺序复原。
- 具备请求队列、服务级限流、并发许可、失败回退和错误分类。

当前项目继续使用每批最多 8 段、5000 字符并校验所有 ID。OpenAI 兼容服务并发 1；Microsoft/Google/Azure 等普通机器翻译服务最多并发 10 个批次，与沙拉翻译普通服务的默认并发池一致。后台另设全扩展总并发 10，避免多个 iframe 的并发相乘。暂不照搬服务级复杂批协议。

## 缓存

- CRX 通过后台 `queryParagraphCache` / `setParagraphCache` 管理段落缓存。
- 缓存与翻译服务、语言和段落身份关联。
- 缓存命中与网络翻译走同一回调和渲染链路。

当前项目已有等价的本地持久缓存：服务/模型或端点、源语言、目标语言、原文组成缓存键；1000 条 LRU 上限，30 天过期，设置页可查看和清除。

## 性能与稳定性

- 长 DOM 遍历按约 16ms 时间片主动让出主线程，优先使用 `scheduler.postTask`，其次 `requestIdleCallback`。
- 记录段落发现、排队、请求、渲染和失败原因等性能指标。
- 动态观察器可暂停、取消并重新建立，避免页面切换后的陈旧任务。
- 对翻译结果采用延迟提交，减少不可见区域 DOM 修改和滚动锚点变化。

当前项目正文上限为 240 块，规模较小，暂不加入完整性能遥测；保留滚动代次检查、AbortController、延迟渲染及动态观察器清理。

## 采用与不采用

采用：

1. 动态模式而非默认全页翻译。
2. 可见范围观察与请求/渲染解耦。
3. 段落级缓存。
4. DOM 节点标记、动态新增正文监听和自身变更过滤。
5. 独立的全页翻译概念不作为默认行为。

不采用：

1. 数百条站点专用规则及云端规则同步。
2. 自动接管 PDF、iframe、Shadow DOM、字幕和图片翻译。
3. 会员、遥测、术语云同步和服务端上下文系统。
4. “立即翻译到底部”功能；这会增加付费接口消耗，且不属于当前需求。
