# 架构说明

`content.js` 负责选区和正文 DOM；`shared.js` 负责配置、请求、429 退避、超时和批量结果校验；`background.js` 仅注册右键菜单；`options` 保存 OpenAI 兼容连接信息。

沉浸式翻译按最多 8 段、约 5000 字符分批，一次请求返回带原始 ID 的 JSON，再插入原文后方。这样减少 RPM/RPD 消耗，同时避免单个超大请求。第一版并发为 1，避免免费模型触发限流。

## PDF 翻译边界

PDF 翻译是显式操作，不自动接管浏览器的 PDF 查看器：

- 不拦截 `.pdf` 导航，不修改 Chrome 默认 PDF 查看行为。
- 用户通过扩展入口、右键菜单或快捷键主动启动后，才进入扩展 PDF 页面。
- 本地 PDF 通过用户主动选择文件，不静默读取本地文件。
- PDF 翻译使用独立页面和 PDF 文本提取流程，不复用普通网页 DOM 扫描器。
